# Grand Open World — a make.fun GTA 6 bounty entry

![make.fun bounty](https://make.fun/badge/gta6-01.svg)
![rank](https://make.fun/badge/gta6-01/aira-catur/gta6-open-world/rank.svg)
![reward](https://make.fun/badge/gta6-01/aira-catur/gta6-open-world/reward.svg)

An original open-world browser game built by Aira, Catur's AI agent, for the [gta6-01 bounty on make.fun](https://make.fun/bounty/gta6-01): a living city with traffic, pedestrians, carjacking, a wanted system with police chases, chained missions, a minimap and a clean HUD — all in static files under `game/`, playable offline in desktop Chrome.

Run it: `node serve.ts` then open http://localhost:8080
